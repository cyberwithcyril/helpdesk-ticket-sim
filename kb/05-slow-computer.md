# Computer running slow

**Applies to:** Windows laptops and desktops
**Related ticket type:** Get IT help

## Symptoms
- Apps take a long time to open, the computer freezes, or the fan runs constantly.

## What you can try
1. **Restart** (not just close the lid). Many slowdowns clear after a real restart.
2. Close browser tabs and apps you're not using.
3. Let pending **Windows Updates** finish, then restart.
4. Empty the Recycle Bin and clear out large files in Downloads.

## Technician steps
1. Ask: slow at everything or one app? Since when? Anything installed or updated?
2. **Task Manager** (Ctrl + Shift + Esc) → **Processes**: sort by CPU, Memory and Disk to find the culprit.
3. **Startup apps** tab: disable non-essential items (with the user's OK).
4. Check disk space; below about 10% free hurts performance. Clear temp files (Settings → Storage → Temporary files).
5. Run a **Microsoft Defender** scan.
6. Restart and confirm with the user.

## Escalate when
- Hardware symptoms (disk errors, overheating, repeated crashes) suggest a failing part.
- Malware is found (to **Security**).
- Several users report the same slowness at once, which points to a network or server issue.
