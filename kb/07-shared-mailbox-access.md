# Access a shared mailbox

**Applies to:** Microsoft 365 shared mailboxes (e.g. support@)
**Related ticket type:** Password or Account Access

## Symptoms
- You were given access to a shared mailbox but don't see it in Outlook.
- You need access to a team inbox.

## What you can try
**Outlook on the web:**
1. In the folder list, right-click your account name.
2. Choose **Add shared folder or mailbox**.
3. Type the full address (e.g. `support@company.com`) and click **Add**.

**Outlook desktop:** new access usually appears automatically within about an hour after restarting Outlook.

Don't have access yet? Submit a request and include **who approved it** (usually the mailbox owner or your manager).

## Technician steps
1. Confirm approval from the mailbox owner or manager.
2. Microsoft 365 admin center → **Teams & groups → Shared mailboxes** → mailbox → **Members → Edit** → add the user.
3. Check the permission types: **Read and manage** (Full Access), **Send as**, **Send on behalf**. Grant only what was requested.
4. Optional: turn on copying sent items to the shared mailbox so replies are visible to the whole team.
5. Permissions can take time to apply. If it doesn't appear, have the user add it manually by full address.

**Removing someone:** remove them from Members **and** confirm Send As is gone too. Refresh the admin view before trusting the counts.

## Escalate when
- The mailbox needs more storage or an archive (licensing).
- The access request has no approval.
